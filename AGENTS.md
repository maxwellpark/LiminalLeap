# Working in this repo

- Commits: a single subject line, no body, no Co-Authored-By or session links.
- PR descriptions: short. One line of context, a sentence or two per change, then what was verified. No "Generated by" footer.
- Code comments: match the surrounding code. Short, and say why rather than what.

# Traps

- `check.sh --fast` hands every built assembly to the compiler, so it can't catch an asmdef missing a reference (the PlayMode tests once lacked `Unity.TextMeshPro`). A real Unity compile does: batch mode with `-quit` resolves packages and compiles every assembly even without a licence, then stops.
- The generator rerolls a repeated or unscheduled piece only 16 times before taking what it rolled, so with one plain prefab it places stray exits. Tests that build a generator give it several plain pieces.
